# Medical Review Consultants — Website

A modern, dependency-free static site for [Medical Review Consultants](https://www.medreviewconsultants.com), a Bozeman, Montana consulting firm supporting healthcare facilities with Medicare utilization review, physician peer review, RAC appeals, and staff education.

The design centers on trust and calm: a deep navy / teal palette, Source Serif 4 + Inter typography (self-hosted), and an animated Three.js hero — a slowly drifting field of light points — that runs on every page.

## Structure

```
index.html              Home
services.html           Service detail (anchors: #utilization-review, #peer-review, #rac-appeals, #education)
working-with-mrc.html   Engagement process and billing
resources.html          External references
contact.html            Contact details + form
css/style.css           Design system (custom properties, no framework)
js/scene.js             Three.js hero scene
js/main.js              Nav, scroll reveals, form handling
vendor/three.module.min.js   Three.js r165, vendored (no CDN dependency)
assets/fonts/           Self-hosted variable fonts (latin subsets)
assets/img/             Page imagery (see "Imagery" below)
scripts/generate-images.mjs  AI image generation
```

There is no build step. Every page works from any static host.

## Preview locally

```sh
python3 -m http.server 8000
# or: npx serve
```

Then open http://localhost:8000. (The ES-module scripts require http://, not file://.)

## Imagery

The repo ships with abstract placeholder art in `assets/img/`. To replace it with photographic imagery generated by OpenAI's GPT Image model:

```sh
OPENAI_API_KEY=sk-... node scripts/generate-images.mjs          # all six images
OPENAI_API_KEY=sk-... node scripts/generate-images.mjs montana  # just one
```

- Defaults to model `gpt-image-2`; set `IMAGE_MODEL=gpt-image-1` if your account doesn't have access.
- Prompts live in the script and share one art direction (soft natural light, navy/teal undertones, nothing readable on any document) so the set feels like a single photo shoot.
- Output lands on the same filenames the HTML references, so no markup changes are needed. Re-run any single image until you like it.

## Contact form

The form on `contact.html` opens the visitor's mail client with a composed message (no backend required). To switch to a hosted form service such as [Formspree](https://formspree.io):

1. Set the form's `action` to your endpoint and `method="POST"`.
2. Remove the `#contact-form` submit handler at the bottom of `js/main.js`.

## Accessibility & performance notes

- The Three.js scene respects `prefers-reduced-motion` (renders a single static frame), pauses when off-screen or when the tab is hidden, and caps device pixel ratio at 2.
- Semantic landmarks, skip link, focus styles, and labeled form controls throughout.
- Fonts are preloaded; images are lazy-loaded with explicit dimensions.
